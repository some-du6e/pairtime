# Third-party material that pairtime's own packages embed, or that their
# code was ported from, and that isn't a Go module. `tools/release notices`
# finds every module's license through the binary's build info, but nothing
# there points at material like this, so it's listed here.
#
# One entry per line: the package's directory, the license or notice file,
# and what the material is, as THIRD_PARTY_NOTICES.txt should name it. Both
# paths are relative to the repository root and use slashes. A binary's
# notices reproduce the file when the binary links that package. Every line
# is checked on every run, binaries that don't link the package included, so
# a path that stops existing fails the build instead of dropping a notice,
# and so does a directory that holds no Go package, such as pkg/redact/rules
# (docs/spec/update-manifest.md, THIRD_PARTY_NOTICES.txt).
#
# The internal/webui lines are the npm packages with code in the local
# dashboard that internal/webui embeds: one line per license or notice file,
# copied word for word from web/node_modules into
# internal/webui/notices/<package>/. tools/ci/npm_notices.py, which web.yml
# and release.yml run on the dashboard they build, fails unless these lines
# name exactly the packages in that build, at the versions it bundles, and
# the copies match node_modules byte for byte.

pkg/redact testdata/redact/presidio/LICENSE Presidio's pattern recognizers (presidio-analyzer 2.2.366), ported to pkg/redact
internal/webui internal/webui/notices/svelte/LICENSE.md svelte 5.57.3 from npm, bundled into the local dashboard in internal/webui
