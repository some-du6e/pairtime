# Release public keys. The pairtime client compiles this file in and
# accepts an update manifest only if one of these keys signed it
# (docs/spec/update-manifest.md). One key per line; lines starting with #
# are comments.
#
# To add a key, run `go run ./tools/release keygen` from the repository
# root. It appends the public half here and prints the secret half once.
# The first key's secret half becomes the RELEASE_SIGNING_KEY secret. A key
# that replaces another stays offline until clients trust it, because the
# release that adds it must be signed with the current key (the spec's
# Replacing a key). Never put a secret key in this file.
