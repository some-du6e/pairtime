## A related point: 6.3's two windows

SM assumes the agent sees Sam switch between iTerm's two windows and knows which session each window hosts. DESIGN's focus source on macOS is `NSWorkspace` app activation (DESIGN 3.3's table, CP 3.3), which reports a change of app, not of window, and both windows belong to the one iTerm process, whose process tree holds both sessions. So the agent DESIGN describes would record 6.3 the way 6.3-tabs records it, and score it as above. Telling the windows apart needs a window identity, such as the Accessibility API's focused window, which needs a permission CP 3.3 avoids, and a map from each window to its sessions.
