# Erratum: SM 6.5's first prompt is 87 characters, not 95

Date 2026-11-19. Raised by WP-FX2. Status: decided 2026-11-20 by the orchestrator for Karim: SM keeps 95 characters and its quote gains "can you", so the quote has the length SM gives it. No row or total changes.

## Input

SM 6.5, row 20:00: Alex types "the navbar overlaps the hero on mobile, fix the css so the hero starts below the navbar" (95 characters) and sends it at 20:01:00.

## Expected

The length SM gives is the length of the text it quotes.

## Computed

The quote has 87 characters, all ASCII. With SM's 95 the lead is 120 + 63 = 183 s, 95 / 1.5 = 63.3 rounded to a whole second as SM rounds T2's, and starts at 19:57:57. With 87 it is 120 + 58 = 178 s and starts at 19:58:02. Both start before the window, so 20:00 is `P` 60 either way and the hour still credits 1,490 s.

## What the fixture does

The `prompt.submit` event carries SM's count, `len_chars` and `typed_len_est` 95, as FX1 did for [6.4's prompts](2026-11-19-sm-6.4-prompt-lengths.md). `prompts.json` quotes the text word for word and names this erratum.

## For Karim

Fix the quote or the number. "the navbar overlaps the hero on mobile, can you fix the css so the hero starts below the navbar" has 95 characters, and with it the fixture changes only in `prompts.json`. Changing the number to 87 changes the event's two lengths, the anchor's lead to 178 s, and `prompts.json`'s `len_chars`, which then matches the quote and names no erratum.

## Decision

Fix the quote. SM 6.5's 20:00 row now reads "the navbar overlaps the hero on mobile, can you fix the css so the hero starts below the navbar" (95 characters). Either length starts T1's lead before the window, so no credited second depended on the choice, and keeping SM's number leaves the fixture's events, leads and rows as they were. `testdata/timelines/6.5` quotes the new text and no longer names this erratum. Besides `prompts.json`, only strings changed: gen.py, `expected.json`'s errata list, two notes in `anchors.json` and the README's Errata row. `events.jsonl` and `hunks.json` are byte for byte the same. The sections above describe the fixture before the decision.
